R’s strength lies in both its statistical capabilities and its open-source nature. Its code is freely available to inspect, modify, and improve, supporting a global community of statisticians, data scientists, and developers.

R packages extend the language with reusable functions, data, and documentation. Community members develop packages for many academic domains (see CRAN Task Views), allowing you to build on established and emerging analytical methods.

2.1 Installing packages

Start by installing the packages below from CRAN in your R console. You generally install a package once per R library, then load it in each session where you need it. Later activities introduce additional packages as needed.

Code
install.packages(c("httr", "jsonlite", "glue", "ellmer", "shiny"))

For the API connection examples, load these two packages:

Code
library(httr)
library(jsonlite)

These commands normally complete without printing output. If R reports that a package is missing, install it in the R session you are using, then try loading it again.

The workshop’s call_claude_AIMECON26.R helper is an R script, not a package to install with install.packages(). It defines call_claude() and uses httr and jsonlite to communicate with Anthropic’s API.

2.2 Individual package details

Here are the main roles of these packages in the workshop:

Package Workshop use
httr Send HTTP requests to an API.
jsonlite Convert between R objects and JSON data.
glue Insert values into reusable prompt templates.
ellmer Manage conversations with LLMs from R.
shiny Build interactive web applications with R.

The httr maintainers recommend httr2 for new work; httr is now superseded. We retain httr here because the workshop helper depends on it. Installing httr2 does not replace that dependency.

We’ll explore prompt templates and JSON in Practical Tools, and web applications in R Shiny.

2.3 Generative AI packages

Several R packages provide interfaces to large language models (LLMs). We’ll use ellmer for conversational interactions. For other options, see the LLM-specific R packages in the reference materials.
