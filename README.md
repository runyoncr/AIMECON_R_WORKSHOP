# Integrating Generative AI into R Workflows: From APIs to Shiny Apps

This repository contains the source materials for *Integrating Generative AI into R Workflows: From APIs to Shiny Apps*, a Quarto book originally developed as a hands-on workshop for AIMECON. The book walks through connecting to and working with generative AI (LLM) APIs directly from R, covering topics such as setting up API access and keys, understanding core generative AI concepts and model parameters, building conversational and batch-processing workflows, chaining prompts together, and integrating AI capabilities into interactive Shiny applications.

While written as workshop companion material, the book is fully self-contained and structured so that individuals can also work through it independently, at their own pace, to learn how to bring generative AI into their own R projects.
